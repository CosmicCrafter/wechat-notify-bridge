# DOC-01 开发者文档网站升级

基线：已发布服务 1.18.0 / a33517f，插件 1.11.0。用户确认的 DOC-01 原型用于视觉和交互，现有 Markdown、OpenAPI、Skill 和示例继续作为技术事实源。隔离分支 codex/doc-01；本轮不改生产、不合并 main、不部署或推送正式发布。

## DOC-01A：静态页面与渐进交互

在现有 render-docs.mjs / build_developer_kit.py 链路中实现原型首页、分组导航、正文、右侧目录、全文搜索、代码复制、主题和窄屏导航。frontend/docs 只维护展示模板、导航元数据和本地样式/脚本，不复制原型中的文章快照或预生成搜索数据。

文章从有效 Markdown 静态渲染。正文、目录、Markdown/OpenAPI/文档包链接不依赖 JS；仅搜索、复制、抽屉和主题由同源外部脚本增强，原 CSP 不增加 unsafe-inline。公开文件仍只能来自构建白名单；新增 JS/TXT MIME，不开放目录或服务器文件。

实际验证：7 项 Python 定向测试、7 项既有前端测试、构建、格式及项目一致性检查通过；1440×900 和 390×844 实际浏览器检查首页/文章/导航/全文搜索/空结果/取消、代码复制到剪贴板、主题跨页保持。手机首页与正文无整体横向溢出，代码块独立横滚。无 JS 阅读通过隔离测试入口的 CSP script-src 'none' 实际阻止脚本执行，静态正文及导航仍可用；这不是生产公网验证或全局浏览器设置验证。

DOC-01B 的资料包/AI 索引一致性保护，以及 DOC-01C 的完整回归和无历史 AI 验收尚待后续本轮提交补齐。DOC-01D 不在本轮范围。
