# 项目重构验收记录

状态：本地候选版，未替换生产服务。

## 已完成

- 应用入口只负责组装；HTTP 安全策略与启动、关闭生命周期独立。
- 通道路由使用内置驱动注册表；飞书入站处理独立于出站适配。
- 公共错误从微信协议包移到 core，并保留旧导入兼容。
- 管理页采用独立 frontend 源码、固定构建清单、统一设计变量与响应式布局；增加 Bot 概览、搜索与筛选。
- 密钥列表在手机端呈现为卡片；会话页延续已验收的长按、归档、草稿、附件和任务交互，统一基础配色与通用应用措辞。
- 增加本机启动入口；首次创建独立凭据，检测到残缺凭据或孤立数据库时拒绝自动覆盖。
- 完善贡献、安全、架构文档；前端构建一致性纳入项目检查；源码包包含前端、示例和开发者接入资料。

## 验证证据

- 既有全量测试：297 项通过。
- 新增运行时测试：6 项通过，覆盖重复启动、启动失败资源清理及本机密钥保护。
- 与重构前备份比较：OpenAPI paths 与 components 完全一致。
- 共享文件、文档链接、第三方资源校验、前端构建一致性检查通过。
- 本地浏览器验证管理登录、Bot 搜索、密钥列表、开发者页；390px 视口验证会话登录、发送回复与附件面板。测试使用独立临时数据库，没有向真实 Bot 发送消息。
- Python wheel 构建通过；从源码压缩包解压的本机入口成功启动，健康检查、管理页面和带认证 Bot API 均通过。浏览器验收不等于真实手机微信／飞书端到端验收。

## 兼容与边界

没有改动数据库结构或密钥算法。`/bridge`、旧 `/wechat` 反向代理兼容及现有调用方协议保留。

这是轻量单进程模块化重构。管理页功能文件仍共享私有页面状态，不是相互独立的 ES 模块。微信业务与部分存储仍有耦合；目前未实现动态加载第三方通道、多租户或多进程扩容。不要据此宣称全部领域层已完全解耦。

上线时仍需按部署文档备份数据库和对应 secrets，使用独立镜像标签并保留旧容器，再验证国内直连与 AI 回调代理。此次本地验收未证明生产回调在新版本上已恢复或通过。
