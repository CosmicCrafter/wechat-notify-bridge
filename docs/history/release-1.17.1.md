# 1.17.1：发布格式检查修正

1.17.0 的 R3 真人收发、账号及数据恢复验证通过后，远端 CI 发现 `mcp/server.py`、`services/bridge.py` 两处遗留 Python 格式不符合 Ruff。按现有格式规则修正，两文件 AST 比对一致，没有新增功能、依赖或数据库迁移。

同时更新版本信息及生成的接口/接入资料。1.17.0 稳定标签作为已发生的发布记录保留，不移动或强制覆盖；1.17.1 使用新的稳定标签。

1.17.0 与 1.17.1 的数据库和账号完全兼容，二者之间的代码回退可沿用当前数据；回退到 v1.16.0 仍必须执行[匹配旧结构的恢复流程](release-1.17.0.md)，封存新增消息并保留当前有效授权，不能直接使用升级库。
