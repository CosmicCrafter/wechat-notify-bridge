# 1.9.0 项目结构整理

- 服务器改为 `src/wechat_bridge/` 包；新增 `pyproject.toml`，页面资源随 Python 包安装。
- 拆分应用组装、HTTP 路由、消息服务、持久化和微信协议模块。
- Admin、手机会话、OAuth 页面和第三方资源分目录维护；公开 URL 保持原样。
- 技术文档集中到 `docs/server/`，部署示例移到 `server/deploy/`，初始化脚本移到 `server/scripts/`。
- 新增共用文件同步检查和可重复源码打包命令。

## 升级

HTTP API、MCP 工具、Cookie 路径、数据库表和加密格式保持兼容，没有新增数据库迁移。服务器版本为 1.9.0，插件仍为 1.4.2。

使用 Docker Compose 的部署者重新构建镜像即可，保留原有数据与 secrets 挂载。手动启动者先 `pip install ./server`，将入口由 `app:app` 改为 `wechat_bridge.app:app`。自行编写的脚本如果导入旧的 `engine`、`portal` 等内部模块，需要改成完整包路径；内部 Python 导入路径不再兼容旧布局。

本地源码整理与线上升级是独立步骤。应先验证安装包、测试和空数据库容器启动，再切换生产容器；不能仅凭目录整理完成就认为线上已经升级。
