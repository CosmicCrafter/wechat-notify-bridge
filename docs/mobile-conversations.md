# 手机对话管理（1.7.1）

会话列表分为“对话”和“已归档”。点击行进入聊天，手机端长按会话约半秒打开底部操作面板，聊天页也可长按标题；手机端不显示三个点。桌面端保留操作按钮。列表左滑露出删除按钮、右滑收起；聊天内容区从左侧边缘右滑返回列表，系统返回键也支持列表/会话导航。上下滚动、输入框和横向代码/表格区域不触发返回手势。

## 归档与重名

归档保留消息正文，停止该对话收发及后续事件投递；手机端只能阅读。名称唯一性范围为同一 API 客户端下 `active=1 AND deleted=0` 的对话，归档记录可以重名。不同稳定 conversation_key 可以复用归档记录的名称；同一个 key 仍复用原对话，避免客户端重试自动新建。恢复归档时遇到同名有效对话返回 409，请先处理冲突；恢复后如需云端自动唤醒，需在 AI 宿主重新启用订阅。

旧数据库的无条件名称唯一约束迁移为条件唯一索引，迁移保留对话 ID、名称、稳定 key 和状态。原 API 的 active=false 对话也作为归档显示。

## 删除与存储

删除必须在页面明确确认。删除清理通知桥的消息正文、已读位置及云端回调订阅，停止原对话并移出列表；不删除微信、ChatGPT 或 Codex 自身保存的记录。保留最小对话标识、入站去重标识和无正文发送回执，避免旧消息重放与旧客户端自动重建。已删除的稳定 key 不会自动恢复。

SQLite 删除释放的页可由后续消息复用，数据库文件不保证立即缩小；此版本不在请求中执行阻塞全库的 VACUUM。历史运维备份有独立保留周期，不会随页面删除同步清除。回退到不识别删除标记的旧程序前必须评估数据兼容性，不应直接用于包含已删除记录的数据库。
