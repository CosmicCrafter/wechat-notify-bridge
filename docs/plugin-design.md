# 插件维护边界

插件只通过 HTTP / MCP 与服务端通信，不直接读取服务器数据库或平台密钥。工具名、鉴权方式和已有客户端配置路径保持兼容；版本以 `mcp-plugin/plugin.json` 等实际发布元数据为准。

- 服务端工具定义与错误映射为唯一维护源，使用 `scripts/sync_shared.py` 同步插件副本。
- Skill 主文件描述授权、身份、会话和可靠发送原则；具体操作按 references 分工，不把所有细节塞入主文件。
- 插件本地配置与运行凭据不得加入发布 ZIP。
- 桌面接收器与云端订阅独立启用；插件安装成功不等于自动唤醒接通。

使用与发布入口：[插件说明](../mcp-plugin/README.md)、[维护手册](MAINTAINER.md)。

原规范研究及当时验收记录已归档：[插件设计历史](history/20261003-plugin-design.md)。
