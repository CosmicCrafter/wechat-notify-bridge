## E3 验证与兼容

应用身份保留原 ID/会话/授权。增加 api_credentials：公开 nbk_ 标识，nb_ + 256 bit 随机 Key，仅 SHA-256 入库。旧 40 位 Key 迁移登记后继续有效，无法得知旧末尾和签发时间时明确未知。正常轮换默认 1 小时、最大 24 小时，最多两把有效/迁移 Key；过期即时拒绝认证，支持主动结束迁移和按 Key 泄露撤销。旧立即 rotate API 保留 40 位新值及全凭据/旧 OAuth 失效语义。新按 Key 轮换不改变独立 OAuth 授权代际；原 API-Key 回调订阅随其具体 Key 撤销/到期失效。停用整个应用同时阻止 Key/OAuth；旧 Key 原值不能回显。应用无有效 Key/OAuth 接收机制时两端回复/任务入口停写并明确原因。

恢复：8 位安全随机验证码，5 分钟、5 次校验、60 秒请求间隔、全站请求限速；只能发送预先验证的本人连接。公网请求统一返回，发送使用 FastAPI 既有 BackgroundTasks 在公共响应发出之后处理，不根据用户名是否存在等待平台网络。验证码仅摘要验证，不进入普通会话/普通查询/日志。绑定需旧管理密码和实际收到的码；恢复/终端重置撤销管理会话并作废旧挑战，保留手机会话、应用 Key、Bot 与加密主密钥。当前密码校验也限制五次失败。旧管理 Key 需密码 Cookie 登录且有有效恢复连接才能显式停用；不自动改变生产认证。

最后恢复连接后端禁止停用、删除与替换本人身份（旧/新入口均保护）。为避免失效凭据无法修复，保持本人身份的 Secret 更新/重新扫码允许当前管理密码确认，凭据改变后原恢复验证失效，需重验才恢复可用；同身份修复仍不解除最后连接保护。原同 owner 绑定约束保留。

通信测试分离“平台响应”与“本人回程”，测试码仅通过通知给本人；已验证 owner / 飞书签名回调中的匹配回程才能确认。测试控制消息不投到业务收件箱、不自动答复任务；配置改变使证据失效。提供受影响应用、默认路由和恢复保护信息，停用/删除/配置变更前显示影响，失败不自动改发另一个平台。新增账号与 Key/连接关键操作审计仅记录动作/公开 ID/时间，不记录秘密。

服务器兜底工具为本地模块 admin_reset，无 HTTP 重置后门；要求交互终端、显式 RESET_ADMIN、私有备份路径，先 SQLite backup+integrity_check，再读取两次新密码。Windows 备份目录收紧 ACL。生成快照不自称恢复验证；隔离测试实际打开旧快照、核验旧密码和完整性，当前应用 Key/Bot/手机 Cookie 保留。
