# Notify Bridge · D0 统一管理端交互原型（v0.3）

**状态：产品原型候选，供集中体验与反馈；不是生产版本，不涉及真实平台/管理认证。**

此包以 2026-10-14 的《统一产品设计与分批实施方案》为设计依据。生产稳定版仍是 **v1.16.0 / 0bddeff**（依据维护者所提供的保护记录），本原型的 `v0.3` 只是设计版本。

## 先看效果

1. 优先打开 `standalone/Notify_Bridge_D0_统一交互原型_v0.3.html`。这是内联 CSS/JS 的单文件离线演示，**不需要网络或安装依赖**。
2. 也可以打开 `prototype/index.html`，其源代码分离为 `styles.css` 与 `app.js`；不要只把 `index.html` 单独移动到其他目录。
3. Windows 若因企业浏览器策略不能打开 `file://`，可从本包根目录运行 `py -m http.server 8000 --directory prototype`，再访问 `http://127.0.0.1:8000`；或更换允许本地文件的浏览器。
4. 该原型默认进入工作台。右上角头像 → 退出登录，可查看未来的登录模拟。初始演示用户名 `admin`、初始演示密码 `DemoOnly123!`。这些是前端硬编码的模拟凭据，**绝非真实认证**。

**特别提醒**：本环境 Chromium 对 `file://` 和 `127.0.0.1` 导航实施了管理员封锁，所以本轮无法声称已经在 Windows 真正双击验收。浏览器 DOM 与交互测试使用 Playwright 将同一份 CSS/JS 注入无网络页面完成。单文件构建已核验不包含外部资源；Windows 双击需在用户机器上再验一次。

## 推荐按顺序试用（全部只是本地内存中的模拟）

| 入口 | 建议点击流程 | 重点观察 |
| --- | --- | --- |
| 总览 | 日常首页 → 预览首次使用 → 再返回日常 | 成熟用户不被长期引导占用屏幕，异常可下钻 |
| 会话中心 | 新建会话 → 选 Claude Code → 发首条 → 继续回复 | 无空会话、明确“已存待领取”而非“AI 已执行” |
| 会话中心 | 返回 Codex 会话 → 提交任务决定 → 看已处理状态 | 普通消息与明确任务答复区分；只能记录一份有效决定 |
| 会话详情 | 右上角更多 → 重命名、置顶、归档/恢复 | 危险操作影响清楚；归档后只读 |
| 投递记录 | 筛选“结果未知” → 查看详情 → 打开原消息 | 诊断不等于聊天；从投递跳到精确消息 |
| 接入应用 | 选“服务器告警” → 接入资料 → HTTP | 资料按用途导出，不混装秘密或 MCP 安装器 |
| 接入应用 | 正常轮换 Key → 仅本次复制 → 关闭后观察 | 新旧过渡和泄露应急不同；旧 Key 不反查明文 |
| 通信连接 | 打开飞书系统通知 → 尝试停用 | 最后一个管理员恢复连接不能直接停用/删除 |
| 通信连接 | 新增连接 → 发送模拟验证 → 回复模拟验证 | “保存了配置”和“收发实测”分开表示 |
| 系统设置 | 选其他节点 → 模拟应用失败 → 再应用成功 | 待选草稿不冒充当前生效；失败保留原配置 |
| 右上账户 | 修改密码 → 错误旧密码 → 正确旧密码 → 退出旧会话 | 仅演示账号，不连接正式认证系统 |
| 帮助 | 对比维护站、AI MCP 接入、业务 HTTP 接入 | 三条路径各自完整，身份与凭据严格分离 |

刷新页面会重置所有模拟操作。演示导出的 `nb_demo_` Key 没有认证用途；导出的 Markdown 只是无密钥说明样例。

## 包内容

- `prototype/index.html`、`styles.css`、`app.js`：**唯一可编辑的原型源**，不依赖第三方图标、CSS 框架或 CDN。
- `standalone/*.html`：由源码脚本自动生成的单文件离线浏览器预览，不作为维护源。
- `tools/build_standalone.py`：可重现的打包脚本，使用 Python 标准库。
- `docs/设计边界与分批实施.md`：现有能力、仅原型能力、后续后端变更的边界。
- `docs/集中验收清单.md`：给业务负责人一次性体验与反馈的清单。
- `tests/test_interactions.py`：交互测试脚本（依赖本地 Python Playwright/Chromium）。
- `preview/*.png`：自动化测试时生成的桌面和 390px 手机截图，只作视觉校对参考。

## 如何维护和构建

```bash
python tools/build_standalone.py
node --check prototype/app.js
# 已安装 playwright / Chromium 时：
python tests/test_interactions.py
```

HTML/CSS/JS 均为人类可编辑源文件。修改 `prototype` 后重新执行构建脚本即可同步单文件预览。无需编译 Vue 或重新下载依赖，不应该直接修改已生成的单文件中的 JS。

## 明确不具备的能力

- **无真实 HTTP/MCP、无生产管理员认证、无平台机器人调用、无真实 Key 签发、无数据保存或浏览器跨端同步**。
- 管理员新建会话、回复和任务决定仅在当前浏览器内存中模拟；**不能据此声称原版 1.16.0 已支持这些管理能力**。
- 移动端展示的是管理员原型布局，不等于已修改实际手机 `/chat/` 页面；两端共享数据在正式后端阶段才需联调。
- 代理节点检测、订阅更新、Key 轮换、验证码找回、管理员恢复和收发验证皆为可点击的模拟流程；安全性须在后端实施与安全回归中另行验证。
- 附件上传、外部平台回执真实查询、离线 AI 主动唤醒等没有实现，也不应被原型文案暗示为已完成。

## 反馈方式

优先按 **页面/场景 + 哪一步别扭 + 理想行为** 反馈。对本轮 D0 原型集中确认后，再按 E0–E4 小批次实施真实服务；不直接拿此原型替换生产 Vue 页面。
