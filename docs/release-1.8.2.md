# 1.8.2 发布前审查修复

本次修复 1 个 P1 和 3 个 P2，不改变插件工具接口，插件仍为 1.4.2。

- OAuth 回调绑定具体 grant_id；刷新令牌沿用授权关系，撤销后不能借另一份授权继续投递。
- Nginx 示例请求体上限改为 6m，服务端单图仍限制 5 MiB。
- 订阅配额只统计未过期的 active 记录；过期记录在后续订阅操作清理，重新激活也遵守容量限制。
- 未授权的 OAuth 注册在 10 分钟后可回收；本人已同意的注册受保护。匿名调用不能通过授权请求延长注册存活期。

## 升级说明

保留原数据和密钥，先备份再升级。OAuth 客户端表自动增加创建时间和授权状态，迁移在事务中执行；现有有效令牌和待兑换授权码对应的客户端保留。

旧 OAuth 事件订阅没有具体授权标识，无法安全推断所属授权，升级后停止投递。请在云端宿主重新启用对应订阅一次。API 密钥订阅与桌面唤醒不受此变化影响。升级不会替用户重新创建云端任务或发送测试微信。

## 验证

回归命令：`python -m pytest server/tests mcp-plugin/tests -q`（从项目根目录执行）。完整回归 **115 项通过**（1 条测试依赖弃用警告）。新增 9 项授权隔离、令牌刷新、迁移、容量恢复和代理配置回归。

另在无网络、无生产数据的全新容器验证空数据库启动、管理员创建客户端、手机会话登录、图片上传读取和 OAuth 注册；在生产数据库的隔离副本验证旧版迁移与原授权令牌保留。真机扫码仍需部署者在自己的微信完成，干净容器检查不等同于另一台机器上完整的微信验收。
