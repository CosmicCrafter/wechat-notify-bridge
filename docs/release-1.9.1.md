## 兼容与生效范围

本机插件 1.5.0 可使用现有服务器 API；远程工具的 Schema、注解和错误分类由服务器提供，需要部署服务器 1.9.1 才生效。仅导入远程插件 ZIP 会更新 Skill 和连接清单，不会更新远程服务代码。

本次交付源码与 ZIP，不自动替换已安装插件，不上传云端发布，不切换生产服务。桌面唤醒仍为实验性适配，没有改变其原有生命周期与投递机制。

严格输入校验会更早拒绝 API 本就不接受的参数。纠正已读工具注解后，部分宿主可能显示写操作提示；这不是新增业务副作用。没有数据库迁移。
