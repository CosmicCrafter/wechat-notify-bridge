# 微信指令

在**已绑定的本人微信**中，直接向 ClawBot 发送文字指令。一个微信账号对应多个 AI 客户端，每个客户端使用独立密钥。

| 指令 | 作用 | 示例 |
| --- | --- | --- |
| `/help` | 返回使用说明 | `/help` |
| `/getkey 名称` | 为新客户端生成密钥 | `/getkey codex` |
| `/list [页码]` | 查看名称、状态与最近调用时间，每页 10 条 | `/list`、`/list 2` |
| `/chats [页码]` | 查看启用聊天的准确回复标签，每页 10 条 | `/chats` |
| `/resetkey 名称` | 重置密钥；已停用的客户端同时重新启用 | `/resetkey codex` |
| `/revoke 名称` | 停用客户端，密钥立即失效 | `/revoke deepseek` |
| `/rename 原名 新名` | 修改名称，保留密钥与去重记录 | `/rename codex 开发助手` |
| `/status` | 查看微信连接与心跳状态 | `/status` |

方括号表示可选参数，不需要实际输入方括号。名称支持 1–32 位中英文、数字、下划线和短横线；英文不区分大小写。`Codex` 与 `codex` 是同一个名字。系统保留名称不能使用。

## 从创建到发消息

1. 在微信发送 `/getkey codex`，收到名称和一串 40 位数字密钥。
2. 在对应客户端的私有 MCP 配置中填写服务器地址和 `api_key`，密钥用双引号包裹，按文本保存。不要粘贴到 AI 对话或公开仓库。
3. 调用 `getCallerIdentity`，应返回 `caller: codex`。这一步不发微信。
4. 通过该客户端发送通知，微信显示 `[codex]`，然后是正文。
5. 对 GPT、DeepSeek 等客户端使用不同名称与密钥。它们需要支持 MCP 或自定义 HTTP API。

也可在 Admin 页面完成相同操作。网页创建或重置密钥时，会显示可复制的 MCP JSON 配置。初始管理员密钥用于管理网页，不能当作 AI 客户端密钥。

Admin 页面还提供“删除密钥”：确认后移除客户端、永久作废密钥，保留历史消息。以后可以同名创建新的客户端。微信指令暂不提供删除操作。

微信 `/status`、`/list` 和 Admin 时间均按 UTC+8 换算，显示为 `2026-10-02 23:54`，不附时区文字。

## 密钥与回复

- 创建和重置时才返回原始密钥，列表不回显密钥。已有客户端再次 `/getkey` 会提示名称已存在，原密钥保持不变。
- `/resetkey` 使旧密钥立即失效；需要给对应 AI 客户端换上新密钥。停用和重置不影响其他客户端。
- 微信命令与 Admin 页面实时操作同一份数据库。页面列表每约 10 秒更新，也可手动刷新。
- 完整的本人文字指令才会执行。机器人发出的文字、他人的消息、语音转写、带引用的文字不作为管理指令；旧指令超过 10 分钟不执行，请重新发送。
- 指令回复通过微信发送；接口接受不代表手机已收到。遇到超时等不确定结果时不会自动重发密钥，可到 Admin 页面查看状态并重置。
- 管理指令及密钥回复不会进入 AI 可读消息列表。普通回复用 `[codex-tibo] 内容` 指定聊天，AI 主动读取；不带标签、未知或含糊标签留在公共收件箱，不自动唤醒任务。
- 心跳按照同一个微信账号的有效收发计时，客户端数量不会增加心跳频率。发指令与收到回复属于正常通信，会顺延 12 小时。


## 手机会话与排版

- `/web`：生成 8 位一次性登录码，10 分钟有效，最多 6 次尝试；新码替换旧码。点击回复下方链接，登录手机会话页。
- `/logout`：撤销所有手机会话页登录和待用登录码，保留聊天记录。
- `/chats`：每页 5 个聊天，可直接点击对应链接，也保留微信标签回复方式。
- 所有指令回复统一使用 Markdown 标题、加粗、分段与命名链接。列表不展示密钥，密钥/登录码回复不会进入普通会话历史或 MCP 收件箱。
- 时间统一显示为 `YYYY-MM-DD HH:mm`，时区固定 UTC+8，正文不额外标注时区。
