# 微信 Markdown 排版指南

本指南适用于通过微信通知插件发送到微信 ClawBot 聊天的消息。前半部分列出能用的格式及其限制，后半部分列出不能实现的格式。其他微信消息渠道、客户端版本可能有不同表现。

## 能用的格式

### 标题与文字样式

| 格式 | 语法示例 | 显示效果与限制 |
| --- | --- | --- |
| 一级至六级标题 | `# 标题` 至 `###### 标题` | 标题标记不显示，文字加粗；各级标题的字号和视觉层级接近。`#` 后需有空格。 |
| 标题内加粗 | `## **组合标题 Heading**` | 标题和加粗标记均不显示，文字以加粗标题呈现。 |
| 中英文加粗 | `**重点文字 Bold**`、`__重点文字 Bold__` | 文字加粗，两种写法均可。 |
| 英文斜体 | `*Italic abc*`、`_Italic abc_` | 英文倾斜；中文没有明显倾斜效果。 |
| 中文句子中的英文斜体 | `这是 *Important* 内容。` | 其中的英文倾斜，周围中文正常显示。 |
| 英文粗斜体 | `***Bold italic***` | 英文同时加粗和倾斜。 |
| 中文粗斜体的加粗部分 | `***重点文字***` | 中文可加粗，但没有明显倾斜效果。 |
| 删除线 | `~~已取消的内容~~` | 文字中间显示删除线。 |
| 星号转义 | `\*保留星号\*` | 显示为普通星号和文字，不作为斜体标记。 |
| 原生 Emoji | `✅ 😊` | 显示表情，外观取决于设备。 |
| 微信表情名称 | `[微笑] [呲牙]` | 这两种名称可转换成微信表情，正文和表格内均可使用。任意方括号文字不会自动成为表情。 |

### 列表、引用与分隔线

| 格式 | 语法示例 | 显示效果与限制 |
| --- | --- | --- |
| 短横线无序列表 | `- 一项内容` | 显示项目符号。 |
| 星号无序列表 | `* 一项内容` | 显示项目符号。 |
| 加号无序列表 | `+ 一项内容` | 显示项目符号。 |
| 两层、三层嵌套列表 | 每深入一层，增加四个空格缩进 | 可显示逐层缩进的项目符号；下方提供三层写法。 |
| 编号条目 | `1. 第一项`、`2. 第二项` | 可显示原序号，但不会自动重排。连续写两个 `1.`，显示的仍是两个 `1.`。 |
| 引用 | `> 引用内容` | 内容左侧显示引用竖线。 |
| 两层引用 | `> 第一层`、`> > 第二层` | 可显示两层引用。 |
| 引用内加粗 | `> **引用中的重点**` | 引用竖线与文字加粗同时显示。 |
| 引用内英文斜体、删除线 | `> *Italic abc* 和 ~~删除内容~~` | 引用内的英文倾斜，删除内容显示删除线。 |
| 分隔线 | 独立一行 `---`、`***` 或 `___` | 三种写法均可显示横线；前后留空行。 |
| 符号间带空格的分隔线 | 独立一行 `- - -` 或 `* * *` | 两种写法均可显示横线；前后留空行。 |

三层列表：

```markdown
- 第一层
    - 第二层
        - 第三层
```

两层引用及引用结束：

```markdown
> 第一层引用
>
> > 第二层引用

这一行回到普通正文。
```

引用结束处需要空行。紧跟在引用后、没有空行隔开的普通文字，可能继续显示在引用区域内。

### 换行与段落

| 写法 | 显示效果与限制 |
| --- | --- |
| 直接换行 | 第一行和第二行分行显示。 |
| 行尾两个空格，再换行 | 可分行显示。 |
| 中间留一个空行 | 可分隔段落，也可结束前面的引用。 |

### 代码

| 格式 | 写法 | 显示效果与限制 |
| --- | --- | --- |
| 行内代码 | 用一对反引号包围内容 | 显示代码底色；适用于短代码和字段名。 |
| 含反引号的行内代码 | 内容两端各放两个连续反引号 | 整段显示代码底色，内部的单个反引号保留；下方提供完整写法。 |
| 行内代码中的小于号 | 用反引号包围 `a < b` | 半角小于号正常显示在代码区域内。 |
| 反引号围栏代码块 | 用独立行的三个反引号包围内容 | 显示独立代码区域、语言标签和复制入口，内部 Markdown 标记保留原样。 |
| 波浪号围栏代码块 | 用独立行的三个波浪号 `~~~` 包围内容 | 可显示独立代码区域。 |
| 代码语法着色 | 开始围栏后紧接语言标记 | 下表中的六种语言可显示对应标签和语法颜色。 |

行内代码：

```markdown
字段名是 `order_id`，表达式是 `a = 1 + 2`。
比较表达式是 `a < b`。
```

含反引号的行内代码：

```markdown
``包含 `code` 的文字``
```

反引号围栏代码块：

````markdown
```python
total = 1 + 2
print(total)
```
````

波浪号围栏代码块：

```markdown
~~~
alpha = 1
**这里保留星号**
~~~
```

支持语法着色的语言：

| 语言 | 开始围栏后的标记 |
| --- | --- |
| Python | `python` |
| TypeScript | `typescript` |
| JavaScript | `javascript` |
| JSON | `json` |
| SQL | `sql` |
| Bash | `bash` |

其他语言及语言标记的缩写未列入本指南的支持范围。

### 表格

支持表头、数据行，以及左对齐、居中和右对齐：

```markdown
| 项目 | 状态 | 数量 |
| :--- | :---: | ---: |
| 资料收集 | 已完成 | 12 |
| 内容复核 | 待处理 | 3 |
```

| 对齐标记 | 含义 |
| --- | --- |
| `:---` | 左对齐 |
| `:---:` | 居中 |
| `---:` | 右对齐 |

表格需要表头下方的分隔行。单元格内支持加粗、删除线、行内代码、命名链接、原生 Emoji，以及上述微信表情名称：

```markdown
| 格式 | 内容 |
| --- | --- |
| 加粗 | **加粗文字** |
| 删除线 | ~~删除内容~~ |
| 行内代码 | `count = 2` |
| 链接 | [微信官网](https://weixin.qq.com/) |
| 原生 Emoji | ✅ 😊 |
| 微信表情 | [微笑] [呲牙] |
```

### 链接

| 格式 | 语法示例 | 显示效果与限制 |
| --- | --- | --- |
| 带名称的内联链接 | `[微信官网](https://weixin.qq.com/)` | 显示带链接样式的名称。 |
| 裸网址 | `https://weixin.qq.com/` | 网址显示为链接样式。 |
| 尖括号网址 | `<https://weixin.qq.com/>` | 网址显示为链接样式。此处只指完整网址写法，不代表任意尖括号内容都能正常显示。 |

### 比较符号与文字样式

全角小于号 `＜` 可以与后续的文字加粗一起使用：

```markdown
CPU＜80%时为**正常**，本行结束。
```

此处“正常”可显示为粗体。半角小于号 `<` 放在行内代码中也可正常显示；直接放在普通正文中时，存在下文列出的组合限制。

## 不能用的格式

这里的“不能用”指不能得到该语法通常对应的排版效果；文字本身可能仍会显示，部分标记也可能被去掉。

### 标题、文字与扩展样式

| 格式 | 语法示例 | 实际限制 |
| --- | --- | --- |
| 下划线式标题（Setext） | 文字下一行写 `===` 或 `---` | 不能形成对应的一级、二级标题；`===` 可原样显示，`---` 可成为分隔线。 |
| 中文斜体效果 | `*中文斜体*`、`_中文斜体_` | 没有明显倾斜效果；中文粗斜体也只体现加粗。 |
| 加号下划线 | `++Underline 下划线++` | 加号原样显示，不会生成下划线。 |
| HTML 下划线 | `<u>Underline 下划线</u>` | 标签原样显示，不会生成下划线。 |
| 高亮 | `==高亮文字==` | 不会出现高亮底色。 |
| 上标 | `x^2^` | 不会上移为上标。 |
| 下标 | `H~2~O` | 不会下移为下标。 |
| Emoji 冒号短码 | `:smile:` | 不会转换成表情。 |
| HTML 标签 | `<b>加粗</b>`、`<i>斜体</i>` | 不会按 HTML 样式排版，标签可原样显示。 |
| HTML 字符实体 | `&lt;` | 原样显示为 `&lt;`，不会转换成小于号。 |
| CSS 与自定义颜色、字体、字号 | `<span style="color:red">文字</span>` | 不支持网页样式设置，也不能用 CSS 控制消息布局。 |
| 隐藏文字 | `\|\|点击后显示的内容\|\|` | 竖线和文字直接显示，不会隐藏内容或生成点击揭示效果。 |
| 折叠内容 | `<details><summary>点此展开</summary>正文</details>` | 标签和正文直接显示，不会生成折叠区域。 |
| HTML 居中 | `<center>居中的文字</center>` | 标签原样显示，不能让正文居中。表格列的居中不受此限制。 |

### 不能叠加的格式

| 格式组合 | 语法示例 | 实际限制 |
| --- | --- | --- |
| 链接名称内加粗 | `[**微信官网**](https://weixin.qq.com/)` | 链接样式仍会显示，但名称两侧的 `**` 保留，不能得到名称加粗的效果。 |
| 普通正文中的半角小于号与后续加粗 | `CPU<80%时为**正常**，本行结束。` | 这段内容会完整显示，但 `**正常**` 的星号保留，加粗不生效。并非小于号本身无法显示。 |

### 列表、链接与图片

| 格式 | 语法示例 | 实际限制 |
| --- | --- | --- |
| 有序列表自动编号 | 连续两项都写成 `1.` | 不会自动显示为 `1.`、`2.`，保留原序号。 |
| 任务复选框 | `- [ ] 待处理`、`- [x] 已完成` | 方括号与 `x` 显示为文本，不会成为任务框。 |
| 引用式链接 | `[微信官网][wx]`，另写 `[wx]: https://weixin.qq.com/` | 不会合并成命名链接。定义行中的网址可能仍显示为普通链接。 |
| 脚注 | `文字[^1]`，另写 `[^1]: 说明` | 不会生成脚注编号及脚注跳转。 |
| Markdown 内嵌图片 | `![图片说明](https://example.com/image.png)` | 不能通过这种写法直接显示图片，可能只留下图片说明文字。此限制不涉及微信原生图片消息。 |

### 代码、换行、公式与图表

| 格式 | 语法示例 | 实际限制 |
| --- | --- | --- |
| 四空格缩进代码块 | 每行开头缩进四个空格 | 不会形成与围栏代码块相同的完整代码区域。 |
| 行尾反斜杠硬换行 | 行尾写 `\` 后换行 | 反斜杠可能保留，不能依赖它实现标准 Markdown 的硬换行效果。 |
| 行内数学公式 | `$E = mc^2$` | 不会排版为数学公式。 |
| 独立数学公式 | `$$...$$` | 不会生成独立的数学公式排版，分数等 LaTeX 命令不会变成数学结构。 |
| Mermaid 流程图 | 在代码围栏后标注 `mermaid` | 显示为带 Mermaid 标签的代码块，不会生成流程图。 |

未列出的语法及格式组合，不视为已经支持。
