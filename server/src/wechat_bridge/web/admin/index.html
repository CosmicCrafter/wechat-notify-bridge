03 / AI 客户端

一个微信，连接多个 AI

为每个客户端创建独立密钥，消息会自动标记来源，如 [codex]。也可以在微信发送 /getkey codex。

名称支持 1–32 位中英文、数字、下划线和短横线；英文不区分大小写。

04 / 手机会话页

在手机上继续对话

打开会话页 ↗

消息下方的链接会进入对应聊天。手机首次登录时，在微信发送 /web 获取登录码，也可以在这里生成。

只用于登录手机会话页；新码替换旧码，使用后失效。

所有手机会话页将需要重新登录，聊天记录会保留。

正常沟通时保持安静。连续 12 小时没有有效收发，才尝试发送一条心跳消息；会话失效时会暂停。回复时使用 [客户端-聊天名] 标签指定聊天；未指明目标的消息留在公共收件箱，不会自动唤醒 AI。
